# Fast Food Landing — часть 1 (Header + Hero)

Готовая верхняя часть страницы. Дальше команда добавляет свои секции (части 2–5)
в тот же проект по правилам ниже.

## Что уже сделано
- **Участник 1** — Header (логотип, меню, кнопка Order Now) + Hero (главный экран
  с бургером, заголовок, абзац, кнопка).
- Собрано по макету Figma, **десктоп-версия**.
- Проект собирается без ошибок (`npm run build`).

## Стек
- React 19 + Vite
- CSS Modules (у каждого компонента свой `*.module.css`)
- Общие токены в `src/styles/variables.css`
- Шрифт **Poppins** (Google Fonts, подключён в `index.html`)
- Никаких сторонних UI-библиотек

## Как запустить
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверить сборку
```

## Структура
```
src/
  main.jsx
  App.jsx                     ← здесь собираются все секции
  index.css                   ← сброс + подключение токенов
  styles/
    variables.css             ← ЦВЕТА, ШРИФТЫ, ОТСТУПЫ (общие для всех)
  components/
    Button/                   ← переиспользуемая кнопка
      Button.jsx  Button.module.css
    Header/
      Header.jsx  Header.module.css  logo.png
    Hero/
      Hero.jsx  Hero.module.css  hero-burger.png
```

## Правила для всей команды (чтобы части состыковались)
1. **Цвета, шрифты, отступы — только из `variables.css`** через `var(--...)`.
   Не писать hex-цвета прямо в компонентах.
2. **Кнопки — только общий компонент `Button`** (`variant="primary"` или `"ghost"`).
   Свои `<button>` не делать.
3. **Один компонент = своя папка**: `ИмяСекции/ИмяСекции.jsx` + `ИмяСекции.module.css`.
   Классы через CSS Modules: `className={styles.имя}`.
4. **Горизонтальные поля** — контейнер `max-width: var(--container)` +
   `padding-inline: var(--page-padding)`. Тогда левые края всех секций совпадут.
5. Тёмная тема, оранжевый акцент `--color-accent`.

## Как добавить свою секцию (части 2–5)
1. Создай папку `src/components/МояСекция/`.
2. Внутри — `МояСекция.jsx` и `МояСекция.module.css`.
3. Подключи в `src/App.jsx` ПОД предыдущей секцией:
```jsx
import МояСекция from './components/МояСекция/МояСекция';

export default function App() {
  return (
    <div className="page">
      <Header />
      <Hero />
      <МояСекция />   {/* твоя секция здесь */}
    </div>
  );
}
```

## Токены (справочно, лежат в variables.css)
- Фон: `--color-bg` `#140f10`
- Акцент (оранжевый): `--color-accent` `#f5821f`
- Текст: `--color-text` `#ffffff`
- Приглушённый текст: `--color-text-muted` `#b8afab`
- Шрифт: Poppins
- Контейнер: `--container` `1180px`, поля `--page-padding`
